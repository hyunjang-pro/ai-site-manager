## 핵심 동작

### 1. 견적 엔진
- 단가 기준: 실제 발행·계약 견적 60건 분석(`../real-interior-quotes-2026.md`)의 2026년 실단가
  - 욕실 1칸 올철거: 원가 약 409만 (철거 80 + 방수 20 + 타일 120 + 도기 50 + 타일공 105 + 폐기물 20 …)
  - 주방 3.2m: 원가 약 384만 (싱크대 60만/m + 상판 16만/m + 철거·폐기 45 + 노무 3일)
  - 도배 24평(합지+1.8T): 원가 약 217만 (실크 롤 4.5만, 장판 1.1만/㎡, 손실 15%)
  - 철거 15평: 순수 철거 약 222만 / 원상복구 포함 약 337만
- `고객가 = 원가 ÷ (1 − 마진율)`, 부가세 별도/포함 선택
- **예상 범위**: 최소(인건비·단순 공정) ~ 기준 ~ 최대(폐기물·양중·자재 추가). 일괄 지역계수로 깎지 않고 실단가를 1.0 기준으로 유지합니다.
- **단가표 스냅샷**: 새 현장을 만들 때 그 시점의 설정 단가를 `unitPriceSnapshot`으로 복사합니다.
  설정에서 인건비·폐기물·사다리차 단가를 바꿔도 **이미 만든 현장 금액은 그대로**입니다(새 현장부터 적용).
- **최소 공사비** 하한(기본 40만)으로 단품 공사 적자 방지
- **누락 1순위 5줄**: 보양 8만 / 관리사무소 신고 8만 / 자재 양중 15만 / 사다리차 소형 12만 / 준공 청소 45만 (한 번에 넣기)

### 2. 현장 변동(수시 견적 업데이트)
- "폐기물 1톤 추가", "바닥 미장 필요" + 금액 → **[견적 즉시 업데이트]** → `처음 324만 → 지금 349만 (+25만)` 누적
- **"미장 불필요", "사다리차 취소", "보양 제외"** 처럼 적으면 마이너스 줄을 새로 만들지 않고
  기존 항목을 찾아 **제외/체크 해제**해서 금액이 바로 줄어듭니다.
- 항목별 **빼기(휴지통) 1개**, **[직전 상태로 되돌리기]**(최대 10단계)
- 견적서의 원가 내역에서 줄마다 **포함/제외 토글** 1개
- 손님 문서(4단계)의 금액·변동 내역이 최신 견적으로 자동 갱신

### 3. 시공 단계 (3단계 · 잠금 없음)
- 계약금·중도금·잔금(금액 자동) → 관리실 신고·보양·사다리차(현장에 해당하는 항목만) → 방수 담수 48시간(사진 3컷 + 아래층 확인) → 준공·잔금 → 추가금 기록
- **강제 잠금 없음**: 권장 순서만 안내하고 어느 단계든 바로 열어 체크·수정
- 업체별 자재 발주 리스트(품명·규격·수량·무게·구매 팁 + 업체별 복사)
- 누수 배상 판례(최대 6,076만원), 방수 하자 3년 경고 상시 표시
- 날씨(Open-Meteo, 키 불필요): **시공 시작일~공사기간** 예보(16일 이후는 계절 기준). 실패하면 조용히 생략

### 4. 손님 문서
- 공종별로 정확한 자재만 출력(도배 견적에 타일이 나오지 않음)
- 제외사항·특약(석면·폐기물 실비·타일/줄눈 보행금지·추가금 4종) 자동 포함
- 인쇄/PDF 저장 지원
